# v2.7.60

引擎 **2.7.60.0**（V20/V21 均重建）。工具 453、lite 59 不变。2.7.59 部署后真机发现的派生示例缺陷。

## 修复

`ToolExamples.PlaceholderValue`（无人工示例的工具按签名派生示例时每个必填参数的占位值）：

| 之前 | 之后 |
|---|---|
| `devicePathJson` → `"["`（词汇表描述里的 `e.g. ["PLC_1"]` 被 `e.g.` 规则截到第一个引号） | `*Json` 参数**先**按名字：数组类（`Path` / `Paths` / `Names` / `Ids` / `Items` / `Entries` / `List` / `Steps` / `Rows` / `Tags` / `Blocks` / `Pages` / `Cultures` / `Numbers` / `Markers` / `Extensions` / `Charts` / `Fields`，不分大小写）→ `"[]"`，其余 → `"{}"` |
| `chartPath` → `C:\Temp\ManageDccChartInterface`（凡 `*Path` 都当文件） | 主机路径只按名字（`filePath` / `importPath` / `exportPath` / `outputPath` / `archivePath` / `csvPath` / `xmlPath` / `logFilePath` / `*FilePath` / `directoryPath` / `referenceAmlPath` / `targetForSoftware` / `path` / 含 `Directory` / `Dir` 的）→ `C:\Temp\<Tool>.<ext>`；其余 `*Path` 是工程内对象路径 → `<Folder/Name>` |
| `e.g.` 值以 `[` / `{` 开头也被采用 | 只采用纯值 |
| `<Folder/Name>` 输出成 `\u003CFolder/Name\u003E` | 派生示例用宽松 JSON 转义 |

规则顺序：固定含义的名字（`*Json`、`softwarePath`、`hmi*Path`、`blockPath`、`deviceName`、`expectedProject`）→ 文档备选值 → 纯 `e.g.` 值 → 路径 → `<name>`。离线加 3 项回归（真机那两条 + 主机路径）。
