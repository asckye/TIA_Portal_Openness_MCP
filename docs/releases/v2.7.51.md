## 修复

- **`WatchTableEntryXml`**：不再写 `ModifyIntention`；`StripReadOnlyAttributes` 在导入前从每一行剥掉它（导出会带出来）。属性序保持 TIA 的字母序：`Address` / `ModifyTrigger` / `ModifyValue` / `MonitorTrigger`（符号行 `Name`）。
- **PLCSIM Advanced 网络模式**（手册 "Interfaces for IInstances" / "IBaseRuntimeManager"）：`SetCommunicationInterface` 先找实例 setter（属性或 `Set…` 方法，PLCSIM Advanced ≤ 5），没有就读 `SimulationRuntimeManager.NetworkMode`，按 `PlcSimAdvancedLogic.NetworkModeFor` 映射（`Softbus` → `Softbus`；`TCPIP` 保留当前 `TCPIP*` 变体、否则 `TCPIPMultipleAdapter`；`ENetworkMode` 名照收；`None` 拒绝），不同才写，写后读回；两条路都不存在时拒绝信息列出实例成员与管理器成员。`Describe(api)` 带 `networkMode`（读不到时 `networkModeError`）。
- **`UploadStationFromPlc`**：目标像 MAC（`xx-xx-xx-xx-xx-xx`）时明说 `ConfigurationAddressComposition.Create` 只收 IP，未下载过的 PLCSIM 实例先下载才有 IP。
