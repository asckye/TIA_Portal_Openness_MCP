# v4.0.0-beta.6 — sixth 4.0 pre-release

This is a pre-release of Automation Engineering Workbench (formerly TIA Portal Openness MCP). Download it by hand to test it.
GitHub keeps 3.3 as the latest stable release. The 3.3 updater and Workbench update check do not offer this build.
[GitHub releases](https://github.com/asckye/TIA_Portal_Openness_MCP/releases)

Unless a release is named, the changes below apply to all eight supported TIA Portal releases, V14 SP1, V15.1 and V16–V21.
V21 ran two candidate builds before publication. The other seven releases have no real-machine beta.6 results.

## Behavior changes you must know

- **Preview again before writing.** Every mutation through `ManageLibraryMasterCopy`, `ManageLibraryTypeVersion`,
  `ManageHardwareObject` or `ManageUnifiedEngineeringObject` now needs the preview's `expectedPlanHash` and exact
  `expectedProjectFile`. The same rule covers `ManagePlcTableEntries` mutations and `ImportPlcWatchTableOffline`.
  On V19–V21, `SetUnifiedGlobalScript` and `SetUnifiedRuntimeSettings` also keep their existing `previewToken`
  requirement. Use the dedicated runtime settings tool for writes, including nested fields.
- **Supply the online address, even for a preview.** `ConnectOnlinePlc` takes `ipAddress` on V15.1–V21 and is unavailable
  on V14 SP1. `DownloadPlc` and `UploadDeviceParameters` take `targetIpAddress`. Use explicit IPv4 addresses.
  A configured address list also governs S7, Web API and OPC UA live access. DNS names, IPv6 and unlisted addresses are
  refused. An empty, unreadable or invalid list denies access. Companion run mode is unavailable while a list is configured.
- **Compile and save before download.** Unsaved or known inconsistent projects are refused. Previews show the target
  address, active matching adapters and whether the target is physical. An automatic interface counts as physical.
  Physical execution requires `confirmPhysicalTarget=true` and Workbench approval. A download counts as simulated only with
  an explicit simulator interface, no overlapping non-PLCSIM adapter subnet and matching instance or exclusive simulator subnet evidence.
  Online writes require approval even when ordinary write approval is off, apart from the PLCSIM-only exceptions.
  Online write plans expire after 15 minutes by default. Generate a fresh preview when one expires.
- **Read enforced presets before composing calls.** `GetSessionState` lists the pinned project and PLC software.
  Pinned parameters disappear from schemas and examples. Conflicting values, rebinding outside the preset, and writes
  whose target cannot be pinned are refused before approval. An equivalent normalized value remains valid.
- **Object paths display names directly.** PLC and HMI paths show spaces and Unicode names. Separators, percent signs and
  control characters are escaped. Older encoded paths remain valid inputs. Regenerate previews for affected names.
- **Check the result of native failures.** Failed Unified script imports or readbacks can expose the recorded phase,
  native return value and cleanup facts in `error.details.evidence`. For `OUTCOME_UNKNOWN`, inspect the target and any
  completed items before another write. A directory import can have applied earlier files.

## What is new compared with beta.5

- **Library objects (API-P1a).** Instantiate a master copy or a released block or Classic screen type version in a project.
  PLC copy and path modes require V20 or V21.
- **PLC tables and compilation (API-P1b).** V15.1–V21 can create empty watch tables and import or export offline force tables.
  `CompilePlcSoftware` and `CompilePlcDiagnostics` can target a block, a block group or, from V16, a standard software unit.
  Preview the exact scope to read its `compilable` status.
- **Hardware (API-P1c).** `ManageHardwareObject` creates and deletes project subnets. From V18 it can also change a device item's type.
- **Unified engineering (API-P1d).** V19–V21 can delete connections and tag tables and set multilingual alarm texts.
  Use `ApplyToolBatch` to apply several reviewed alarms. Creating a V21 graphic list still requires an import.
- **PLC test library (TIA-TEST).** Store scenarios and Test Suite selections, run them in order after one approval and read
  the run history. Test Suite needs V17+, system tests V18+ and application test sets V20+. Export JUnit, FAT/SAT or a
  reproduction report. The `tia test report` command reads stored runs and returns a CI exit code. Unreadable history rows
  remain visible, timestamps include milliseconds and JUnit handles characters forbidden in XML.
- **Online safety and approvals (TIA-SAFE).** The Workbench edits allowed addresses, the online plan lifetime and
  Windows-protected vault entries. Approved calls can resolve a named vault entry in a declared credential parameter.
  `GetApprovalStatus` lists pending approvals, the latest 16 decisions, policy, target entries and vault names.
  Only a person in the Workbench can decide an approval.
- **Tables and batches (TIA-BATCH).** `ExportPlcTagTables` recursively exports a bounded selection. `ConvertEngineeringTable`
  round-trips PLC tag-table XML through CSV or XLSX and edits global DB start values for verified import. CSV preserves
  formula-leading text. XLSX uses plain strings. V19–V21 add paged spreadsheet review for Unified tags and alarms, including
  per-row PLC binding review. Batch writes use each item's stored preview. BATCH-5b moves to 4.1.
- **Project and HMI workflows (TIA-GAPS).** On V15.1–V21, open one secondary project read-only and compare by full project
  path. The reference belongs to its TIA process. Close it explicitly before closing the primary project or disconnecting.
  `GetToolUsage` includes project overview and comparison sequences. V19–V21 can read and write supported nested scalar
  runtime settings. Update existing script modules using the bound preview. See the creation limit below.
- **Engineering guides, exports and examples (ECO-S).** The 32 refreshed Siemens guides identify their V21 reference scope.
  Opt in to `stripVolatile` for repeatable block, type and tag-table XML exports. The compile/export/commit sequence keeps
  Git review explicit. V21's LAD builder adds contacts, comparisons, branches, timers, counters and named FC/FB calls.
  The classic PLC pattern library holds its SCL and LAD candidates until native import and compile evidence exists for the
  particular release and CPU family.
- **Release-specific descriptions (SELF).** DB snapshot read/export starts at V15.1 and value actions require V21.
  Compilation settings expose the simulation flag from V16 and the virtual-PLC flag from V19.
- **Editor and worker fixes.** `ShowObjectInEditor` opens an object directly without write approval. It supports device views
  and, from V15.1, watch and force tables. All releases now share worker session handling, admission and behavior disclosure.
  A status read or restart preview leaves a cold worker stopped. `ExportTechnologyObject` is available on all eight releases.
  `ExportPlcWatchTable` starts at V15.1. V20 library document import admits the documented inactive-culture options.
  `GetOpennessCompatibility` drops the unused `v20OptionWrappersCompiled` field.
- **PLC documents (VMFIX-10D).** V20/V21 accept the tested S7DCL declaration forms, including typed start values after
  `END_VAR`, and report rejected syntax lines. XML comparisons include member attributes, comments and start values.
  Raw remanence differences remain visible. Mixed-format comparisons omit start values because their literal forms differ.
  The full set of changes is in the [changelog](../../CHANGELOG.md).

## Known limitations

- **Unified script creation is refused on V19–V21.** On V21, import returned without creating the module. Create it in TIA,
  then preview and apply `SetUnifiedGlobalScript` with `action=update`. Creation remains closed pending native verification.
- **Four native refusals can still report an unknown result.** This affects `ImportPlcBlock`, `ImportPlcProgramFromDirectory`,
  `InvokeObject` with `SetAttribute`, and `ConnectOnlinePlc`. Inspect actual state before retrying. The correction is planned for the RC.
- **V21 LAD fan-out is limited.** A contact at the start of a fan-out branch is refused after TIA rejected a composite network.
  The maintained `rung` and `rung-boxes` examples are available through `GetToolUsage`. Pattern-library acceptance remains open.
- **V20 SiVArc provider crash.** V20 refuses `ListSivarcBlockDefinitions`, `ManageSivarcBlockDefinition`,
  `ResolveSivarcExpression` and `UpgradeSivarcDefinitions` before native dispatch, including previews.
- **V21 HMI findings remain open.** For an absolute tag, supplying only `plcTag` with a memory address could roll back the binding.
  Supplying `address` explicitly succeeded. `ImportHmiTagTable` failed with a Chinese file name and worked with an ASCII name.
- **Older workers still use STA.** MTA-1 awaits eight-release smoke testing. V20/V21 use MTA. The remaining UNIFY-1 work is due
  for the RC. The V21 technology-object type/version crash guard still applies.
- **Earlier V21 reports still need reproduction.** These cover Unified alarm indicators and transactional screen changes,
  widget binding loss, silent S7DCL import changes, repeated textual-interface transfers, Classic HMI graphic-list export,
  incomplete cross-references and unreadable technology-object instance DBs.
  [Real-machine testing manual](https://github.com/asckye/TIA_Portal_Openness_MCP/blob/master/docs/manuals/real-machine-testing.md#v21-外部报告的风险复现)
- **Late results live in host memory.** Keep the request ID and read-back evidence. After a host restart, inspect the project.
  Some unknown writes cannot be settled automatically. A refused `BuildProjectScaffold` step can still mark the whole write
  unknown. Read its step report. UDT member comments written through `PatchPlcBlockDocument` still lack native verification.
- **Paths and output hints have limits.** Tag, technology, watch-table and external-source group paths can refuse a group
  named `Program blocks` or `程序块`. Directory preview hashes include unrelated nested files. Unreadable files can block
  preview, some preflight paths omit source-directory checks, and a locked input at apply can produce a validation error.
  Supply a suitable explicit target for `ExportPlcBlockDocuments` and `PatchPlcBlockDocument` when default-output guidance is ambiguous.
- **Some failure messages still give incomplete guidance.** HMI connection guidance can suggest a tool that cannot create the
  connection. Losing TIA before a network write starts can produce an exclusive-access refusal.
- **Update signing and transport.** The ZIP and its hash come from the same GitHub release. An account compromise could replace
  both. LAN transport uses plain HTTP, so use a trusted network. A UNC input can contact a file server and expose Windows
  credentials during preview, before approval. The planned S8 change is still outstanding.

## Install it next to 3.3

1. Select `v4.0.0-beta.6` on the releases page. Download `TIA_MCP_Delivery_v4.0.0-beta.6_<date>.zip` and its `.sha256` file.
   Compare the sidecar with `Get-FileHash -Algorithm SHA256 -LiteralPath '.\<downloaded-package>.zip'` before extracting.

   [Configuration guide](../getting-started/configuration.md)
3. Use project copies and connect one host to a TIA process at a time. To remove the pre-release, close its processes and remove its folder.
