## 修复

- **创建后的身份核对**：`ManageUnifiedScreenItem create` 与 `ManageUnifiedScreenLayout create` 改为按精确名称查回 + 计数 +1，后续属性写入使用查回的代理；不再用引用相等。
- **部件内多语言文本**：`propertiesJson` 里任意深度的 `MultilingualText`（`Title.Text`、`Label.Text`、`Caption.Text`…）都按 culture 拆出并逐条读回；只带文本的部件不再留下空的嵌套写入；纯字符串仍被拒绝。
- **`UpdateUnifiedObjectProperties` / `ReadUnifiedObjectProperties`**：改用 UI 模型的嵌套读写——`#AARRGGBB` 颜色可读可写，嵌套部件（报警类四种状态视觉、记录的 `Settings`/`Backup`/`Segment`、运行时设置子对象…）可用嵌套对象一次写入并逐叶读回；集合仍走各自工具。
- 隐藏属性在标量读取里只列一次（`HmiSlider` 的 `EventHandlers` 此前出现两次）。
