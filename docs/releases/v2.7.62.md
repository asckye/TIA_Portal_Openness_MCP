## 去掉离线更新

`scripts/operations/Update-Engine.ps1`：

- 参数只剩 `-Check` / `-Version` / `-Rollback` / `-Force` / `-Repository` / `-InstallRoot` / `-TimeoutSeconds`；`-ZipPath` 与 `-SkipHashCheck` 删除，没有本地 ZIP 分支。
- 只从 GitHub Release 取包：先走 API，API 不通再解析发布页；release 没有 `.sha256` 资产就拒绝更新（SHA-256 校验不可跳过）；github.com 完全不通时直接失败并说明“这台机器访问不到 github.com”，不再建议去别的机器下载。
- 其余不变：引擎 / 配置器在运行就拒绝并列出 pid、备份到 `.previous\`、替换 `runtime\` / `manifest\` 并覆盖其余文件、`-Rollback` 换回上一版、不碰 TIA 与客户端配置。

引擎侧：

- `UpdateLogic.HowToUpdate` 由四步改为三步：停引擎 → 在该机器上运行更新器（需要能访问 github.com）→ 重启并用 `Bootstrap` 看 `serverVersion`；`-Rollback` 在第三步说明。
- `CheckForUpdate` 的描述与 GitHub 不可达时的提示改为“检查连接 / 代理，或打开发布页看最新版本”，不再提离线包。
- 离线测试 `PreflightAndUpdateTests`：断言三步、且任何一步不含 `-ZipPath`。

文档：README（中英）“Start here”、`scripts/README.md` 的更新器一行、交接单部署说明都去掉 `-ZipPath`。
