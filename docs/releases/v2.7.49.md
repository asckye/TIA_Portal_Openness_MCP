## 修复

- **下载 / 上线路由**：`ConnectionConfiguration` 路由树里 CPU 的配置 IP 在 `PcInterface.Subnets[].Addresses`（或 `Gateways[].Addresses`）下，目标接口 `TargetInterfaces[].Addresses` 在 PG 网卡看不到 CPU 时是空的。`SelectDownloadRoute` 现在按 目标接口地址 → 子网 / 网关地址 → `ConfigurationAddressComposition.Create(ip)`（官方；V20 / V21 都有）三级取 `ConfigurationAddress`（它实现 `IConfiguration`），`ApplyConfiguration(address)` 后交给 `Download`；新建的地址走官方 5 参 `Download(IConfiguration, ConfigurationAddress, pre, post, options)`（"Download … to a target with specific IP-Address"）。`GoOnline(softwarePath, ipAddress, …, pgPcInterface)` 同样选路由，V21 走 `OnlineProvider.GoOnline(ConfigurationAddress)`，V20 只有 `GoOnline()`（地址已 Apply）。`ReadPlcBlockFingerprints` 的候选路由、`UploadDeviceParameters` 的地址、`UploadStationFromPlc` 的地址（扫描到的 IP / MAC 可建）一并对齐。响应 meta 多 `targetAddress` / `targetAddressSource`（targetInterface / subnet … / created）。
- **PLCSIM Advanced**：`SetCommunicationInterface` / `SetOperatingMode` 先找具体类型的可写属性，再找每个接口（`IInstance`）上的 setter；写入结果 0/N 与场景 FAILED 时 `operationSuccess=false`、`Ok=false`；powerOff 后 "state now (powered off …)"。
- **监控表**：`EnsureWatchTableEntry` / `EnsureForceTableEntry` 改官方写法：`Entries.Create()` + `SetAttribute`（`%M0.0` / `DB1.DBX0.0` 之类绝对地址进 `Address`，`"Tag"` / `Tag` 进 `Name`）+ `GetAttribute` 读回；`refusedAttributes` / `after` / `readbackVerified` 进 meta；读回不符如实报失败并指向 `ImportPlcWatchTableOffline`。
- **工艺对象**：`GetTechnologyObjects` 递归 `TechnologicalInstanceDBGroup.Groups`，条目带 `Folder`；`ExportTechnologyObject` 接受 `MCP_TO/MCP_PID`（同名多处时要求带文件夹）；`ExportTechnologyObjectsToDirectory` 按文件夹建子目录。

## 待真机（部署 2.7.49 后）

`MCP_SIM` 走 TCPIP 时虚拟网卡 "Siemens PLCSIM Virtual Ethernet Adapter" 目前没有 IP（路由描述 `[no IP]`）——要么在虚拟机里给它配一个 192.168.0.x/24 的静态 IP，要么把实例改成 Softbus（`ManagePlcSimAdvancedInstance register … communicationInterface Softbus`，本版起可写）后看路由树是否出现 "PLCSIM" 接口。然后：`DownloadToPlc {softwarePath:"MCP_PLC", pgPcInterface:"<网卡或 PLCSIM>", targetIpAddress:"192.168.0.1", startAfterDownload:true}` → `GoOnline {ipAddress:"192.168.0.1", pgPcInterface:…}` → `CompareSoftwareToOnline` → `SetWatchTableModifyValue`（读回）→ `ReadPlcSimAdvancedTags` / `WritePlcSimAdvancedTags` / `RunPlcSimAdvancedTestScenario`（有程序后）→ `UploadStationFromPlc dryRun`（MAC）→ `GetTechnologyObjects`（文件夹里的 TO）→ `GoOffline`。
