# v2.7.42

引擎 **2.7.42.0**（V20/V21 均重建）。工具 437 → **447**，默认 lite 清单 56 项不变。本版是"官方 Openness API 全量对齐"计划 [路线图 §2.0](../development/roadmap.md) 阶段 6（选件包）的最后一批 ⑥-③：**SafetyValidation + Test Suite + Teamcenter + CFC**（V21 `Siemens.Engineering.SafetyValidation.dll` / `TestSuite.dll` / `TeamcenterGateway.dll` / `CFC.dll`；V20 的后三者在整体 `Siemens.Engineering.dll` 里，SafetyValidation 是 V21 新增）。2.7.39 审计剩下的 25 个功能类型 / 122 个成员全部改为专用引用，**阶段 6 收口，全部程序集的功能类型缺口为 0**。SafetyValidation 与 Teamcenter 本机、虚拟机都没有许可 / 环境，只有形状检查；Test Suite / CFC 虚拟机装有选件但工程里没有内容，真机只能验空表与 NotFound / NotSupported 路径。
