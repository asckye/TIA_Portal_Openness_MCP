# v2.7.34

引擎 **2.7.34.0**（V20/V21 均重建）。工具 396 → **402**，默认 lite 清单 56 项不变。本版做两件事：修 2.7.33 真机暴露的事务缺陷，以及"官方 Openness API 全量对齐"计划 [路线图 §2.0](../development/roadmap.md) 阶段 4 子批次 ④-①：Step7 软件单元与 `PlcSoftware` 小服务（`SW.Units`、`PlcDocument*`、`PlcChecksumProvider`、`FingerprintProvider`、`PlcBlockWriteProtectionProvider`、`PlcSimulationSettingsProvider` / `VirtualPlcSettingsProvider`、`PlcTagProvider`、`ProcessImageProvider`、类型化的文档导入导出结果）。

## 2.7.33 真机问题的修复

| 问题 | 修法 |
|---|---|
| `RunToolsInTransaction` 内层调用不带 `dryRun` 时按内层工具默认 `dryRun=true` 跑成预览，事务却回报 `committed=true` | `BaseLeftoversLogic.ForceRealExecution` 无论键是否存在都写入 `dryRun=false`（大小写不敏感命中已有键）；离线测试改为断言 `{}` → `{"dryRun":false}` |

## 新增工具（域 PLC-Software / Project）

| 工具 | 动作 | 官方入口 |
|---|---|---|
| `ReadPlcSoftwareUnits` | 类型化读软件单元树：`PlcUnitSystemGroup`（V21 `Name`、单元 / 安全单元数）→ 每个 `PlcUnit` / `PlcSafetyUnit` 的 Name / Author / NamespacePreset / 各语言 Comment / 关系（`RelatedObject` / `RelationType`），`includeContents` 时列出 `BlockGroup`（块 / 组 / 系统块组）、`TypeGroup`（类型 / 组 / 命名值类型文档）、`TagTableGroup`、`ExternalSourceGroup`、`PlcAlarmTextlistGroup` 的名字（各前 200）；`unitKind` all / unit / safety，分页 | "Accessing software unit" / "Accessing software unit underlying objects" / "Accessing the SafetyUnit"：`PlcUnitProvider.UnitGroup`、`PlcUnitBase.*`、`PlcSafetyUnitComposition` |
| `ManagePlcDocuments` | `objectKind=document`（`PlcTypeGroup.Documents` 命名值类型文档）/ `type`（UDT）：`list` / `read`；`export`（`ExportAsDocuments(dir, name)` → `DocumentExportResult` State / 已哈希的 `ExportedDocuments` / 原生消息，拒绝覆盖 `name.*`）；`import`（`ImportFromDocuments(dir, name, importOption)` → `DocumentImportResultForSplDocument.ImportedDocuments` / `DocumentImportResultForTypes.ImportedPlcTypes` + `DocumentResultMessage`，`Find` 回读）；`createFromMasterCopy`（`copyMode`）与 `createFromLibraryType`（`PlcDocumentLibraryTypeVersion` / `PlcTypeLibraryTypeVersion` + `updatePathsMode`，文档的 `CreateFrom` 仅 V21）；容器可以是 PLC 根类型组、`groupPath` 下的用户组或单元的 `TypeGroup` | "Accessing name value type document" / "Exporting UDT as document" / "Importing UDT from document" |
| `ReadPlcChecksums` | `PlcChecksumProvider.Software` / `TextLists`（未编译为 null；不支持的 PLC `supported=false`） | "Accessing Software Checksum" |
| `ReadPlcObjectFingerprints` | 块 / UDT（可在单元内）的离线指纹：`FingerprintProvider.GetFingerprints()` → 每个 `Fingerprint` 的 `Id`（12 种官方 `FingerprintId`）/ `Value`；对象不一致时原生拒绝（提示先编译） | "Changing blocks using fingerprints" |
| `ManagePlcBlockWriteProtection` | V21 `PlcBlockWriteProtectionProvider`：`read`（IsDefined / IsProtected）、`define` / `protect` / `unprotect` / `change` / `remove`（`Change(pwd, null)`）；官方状态机在调用前门控，密码只进 SecureString，原生非法字符校验，回读核对；V20 回 NotSupported | "Setting up write protection of blocks" |
| `ManageProjectCompilationSettings` | `IsSimulationDuringBlockCompilationEnabled` / `IsVirtualPlcDuringBlockCompilationEnabled` 读 / 改：V20 是 `Project` 属性，V21 去掉了这两个属性、改经 `Project.GetService<PlcSimulationSettingsProvider>()` / `<VirtualPlcSettingsProvider>()`；写后回读 | "Updating project properties" |

扩展：`ManagePlcSoftwareUnit` 新增 `unitKind=safety`（系统生成的 `PlcSafetyUnit`：只允许 read / update / 关系，create / delete 在参数门就拒绝）、`createFromMasterCopy`（`PlcUnitComposition.CreateFrom(MasterCopy[, MasterCopyMode])`）、`commentsJson`（按工程语言写 `Comment.Items[i].Text`）；`SetPlcUnitObjectAccess` 也能对安全单元里的块发布；`ReadDeviceItemChannels` 新增 `includeLinkedTags`（V21 `Channel.GetService<PlcTagProvider>().GetLinkedTags()` → 变量名 / 数据类型 / 逻辑地址 / 变量表；V20 回 null 并说明）；`UpdateDeviceAddress` 的 `processImageObName` 在 V21 改走 `Address.GetService<ProcessImageProvider>().AssignProcessImageToOrganizationBlock(OB)`（V20 仍是 `Address.AssignProcessImageToOrganizationBlock`），不再对 V21 报 NotSupported；`ImportFromDocuments` / `ImportBlocksFromDocuments` 的结果改为类型化 `DocumentImportResultForBlocks`，失败时把 `DocumentResultMessage.Message` 附进错误文案，`ImportedPlcBlocks` 名单记到 `LastImportedDocumentBlocks`。

只在 PublicAPI 上学到的事实：V21 的 `Project` 没有 `IsSimulationDuringBlockCompilationEnabled` / `IsVirtualPlcDuringBlockCompilationEnabled`（官方页面仍按 V20 写法举例），只剩两个服务提供者；`Channel` / `Address` 在 V20 不是 `IEngineeringServiceProvider`；`PlcUnitSystemGroup.Name` 与 `PlcDocumentComposition.CreateFrom` 仅 V21；`PlcDocument` 在 PublicAPI 里只有 `Name`（内容要导出后看）。
