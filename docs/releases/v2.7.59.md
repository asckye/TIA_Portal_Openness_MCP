# v2.7.59

引擎 **2.7.59.0**（V20/V21 均重建）。工具 **453** 不变，lite 59。参数描述批次 2——2.7.58 的调用纪律机制（schema `enum` / 失败自动预检 / 派生示例）都从参数描述里取事实，这一版把描述补齐。

## 做了什么

| 项 | 2.7.58 | 2.7.59 |
|---|---|---|
| 有自己 `[Description]` 的参数 | 812 / 2204 | **1310 / 2204**（+498） |
| 无自身描述但词汇表覆盖 | 1002 | 894（全部覆盖，**0 个空描述**） |
| schema `enum` 提示 | 67（51 个工具） | **185（119 个工具）** |

- **枚举型参数 155 个**：取值追溯链是"工具方法 → `Portal.X` → `XxxLogic.Validate...` → `RequireOneOf(param, 数组 / 字面量)` 或 `'param must be one of a/b'` 拒绝文案"；`using Logic = XxxLogic` 别名按文件解析；同名数组（`Categories`、`ExchangeActions`、`ObjectKinds` 在 SiVArc / Test Suite / CFC / 经典 HMI 之间重名）按实际到达的 Logic 类消歧，无法归属的一律不写；`*Path` 参数即使有按种类的校验也不当枚举（`ManageClassicHmiScreenObject.objectPath` 只在 slidein 时是 Top/Bottom/Left/Right）。文案形式 `action: the operation to perform - a | b | c.`，与 2.7.58 的解析规则（独立成段的列表）配套。
- **人工描述 343 个**：275 个不同名字（`typeIdentifier`、`identifier`、`valueJson`、`positionNumber`、`chartName` / `blockName` / `pinName` / `sequenceIndex`（DCC）、`archivePath`、`leftPath` / `rightPath` / `leftVersion`（库比较）、`numbersJson` / `includeBits` / `includeEnumValues`（驱动参数）、`hostUrl` / `instance` / `applicationId`（Teamcenter）、`days` / `hours` / `minutes`（Unified 归档时长）……），全部按名称含义与所在工具写就，不用"名字转空格"的兜底文案（兜底 0 条）。
- 三个 PascalCase 枚举值（`ReadOnly`、`DeleteUnusedTypes`、`SetOnlyHigherUpdatedVersionAsDefault`）加进 `Check-DeadToolReferences.py` 的允许名单（它们是 Openness 枚举值，不是工具名）。
- 修 `ExtractPlcBlockMetrics.path`：绝对文件 / 目录路径。
