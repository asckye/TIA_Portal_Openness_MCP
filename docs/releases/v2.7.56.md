## 修复

- **`Portal.ConnectPortal(projectName, allowStart, info)`**：`GetProcesses()` 非空 → 逐进程 `AttachWithTimeout`（20 s，累计 45 s 预算），记录 `ConnectLogic.Candidate {ProcessId, Attached, HasSession, ProjectNames, Failure}`；`projectName` 命中即停；`ConnectLogic.Choose`：命中工程 → 首个有工程 / 会话 → 首个可附加；`null` → `PortalException(InvalidState, ConnectLogic.Refusal(...))`（"No new instance was started"），除非 `allowStart`；`GetProcesses()` 为空才 `new TiaPortal(launchMode)`。安全拒绝（`EngineeringSecurityException`）照旧立即抛出；未选中的候选全部 `Dispose`。命中的 `projectName` 记为 `_expectedProjectName`（自愈只回绑它）；未命中时 `info.warning` 说明绑到了哪个进程。
- **`Connect` 工具**：`projectName`（可选）、`allowStart`（默认 false）；`Message` 区分"attached to PID n"与"Started a new TIA Portal instance"，`Meta` = `processCount` / `candidates`（每进程一句）/ `boundProcessId` / `startedNew` / `attachElapsedMs` / `warning` / `launchMode`。
- `IsProjectNull` 自愈与 `OpenProject` 里的 `ConnectPortal()` 走同一条路：有进程就绝不自启。
