# v2.7.39

引擎 **2.7.39.0**（V20/V21 均重建）。工具 421 → **437**，默认 lite 清单 56 项不变。本版是"官方 Openness API 全量对齐"计划 [路线图 §2.0](../development/roadmap.md) 阶段 6（选件包）的第二批 ⑥-②：**Startdrive + DCC**（V21 `Siemens.Engineering.Startdrive.dll` / `Siemens.Engineering.DCC.dll`，V20 都在 `Siemens.Engineering.dll` 里）——**Startdrive 34 / 117 与 DCC 13 / 68 的功能类型缺口归零**，选件包只剩 SafetyValidation / Test Suite / Teamcenter / CFC 的 25 / 122；另修 2.7.38 真机暴露的三处 SiVArc 缺陷。虚拟机装有 SINAMICS Startdrive Advanced + DCC（2.7.38 `ReadPortalInfo`），工程有 4 台 G120C，本版部署后可真机验证。

## 修复（2.7.38 真机）

- `ManageSivarcRule` → **`ManageSivarcTableRule`**：`CallTool` 的工具映射建在 `OrdinalIgnoreCase` 上，只差大小写的旧工具 `ManageSiVArcRule` 与它撞成一个键，lite 模式下类型化规则工具不可达。`scripts/checks/Check-DeadToolReferences.py` 新增"工具名不分大小写唯一"闸门（带哨兵自检；对 2.7.38 源码会报出这一对）。
- `GenerateSiVArc`：`Sivarc.Generate(deviceName, plcs, options)` 的 `plcs` 是 PLC **设备**名（真机报 "PLC device '+S1-K1' not found"），引擎现在从 `PlcSoftware` 经 `SoftwareContainer.Parent` → `DeviceItem` 链走到 `Device` 取名，`meta` 同时回 `plcSoftwareNames` / `plcDeviceNames`。
- 通用 `ManageSiVArcRule delete`：删除后从 `Sivarc` 锚点重新解析集合再核对（旧组合代理枚举抛 `EngineeringObjectDisposedException` 并触发连接失败保护），`meta.verifiedOnFreshNavigation=true`。
- `Probe-McpServer.py` 打印 JSON-RPC 错误（此前 "Unknown tool" 静默）。
