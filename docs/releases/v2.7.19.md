# v2.7.19

引擎 **2.7.19.0**，V20/V21 均在本机 PublicAPI 上重建。工具 350 → **359**，默认 lite 56 项不变，其余经 `FindTools` + `CallTool`。本版补齐路线图中剩余的第三方集成候选（PLCSIM Advanced、块可视化、SCL 预检、程序文档、AML 生成、写保护钩子），并完成 E8 工程文件改名。本版没有连接真实 TIA 工程、在线 PLC 或 PLCSIM Advanced 实例；新工具按官方程序集 API 形状与离线逻辑验证。

## 写保护钩子与审计日志

插件（`.claude-plugin/plugin.json` → `hooks/hooks.json`）新增 PreToolUse 钩子 `hooks/tia-write-guard.ps1`：

- 按 `manifest/tools-list.json` 的操作类型审计所有非只读调用（含经 `CallTool` 桥接的目标）到 `%LOCALAPPDATA%\TiaMcpServer\audit\tool-calls.jsonl`，`password`/`secret`/`token` 类参数脱敏；
- 拒绝真实 ONLINE-WRITE 调用（`DownloadToPlc`、站/参数上载、S7 Web / Unified 运行时写值与模式切换、PLCSIM 实例变更与写值、`SetWatchTableModifyValue`），预览调用（`dryRun` 未显式为 false）放行；
- 环境变量：`TIA_MCP_ALLOW_ONLINE_WRITE=1` 放行（仍审计）、`TIA_MCP_WRITE_GUARD=0` 关闭、`TIA_MCP_GUARD_DENY_OPERATIONS` 追加拒绝的操作类型、`TIA_MCP_AUDIT_LOG` 改日志路径。

自检 `scripts/checks/Test-WriteGuard.ps1`（16 项）随 `Build-Release.ps1` 运行。
