## 修复

- **TLS 证书信任**（官方页 "Supporting secure S7 communication TLS"）：S7-1500 FW ≥ 2.9 首次连接在 `ConnectionConfiguration.OnlineLegitimation` 上抛 `TlsVerificationConfiguration`（`CurrentSelection` NonVerified / NonTrusted / Trusted，`PlcName`、`VerificationInfo`），答成 `Trusted` 才能连。`AttachOnlineLegitimationHandler` 取代只在有密码时才订阅的 `AttachPasswordHandler`：总是订阅，密码 / UMAC 提示照旧按给定凭据应答，TLS 提示按 `trustDeviceCertificate` 应答（纯逻辑 `BaseLeftoversLogic.TlsSelectionToApply`），`meta.tlsVerification` 记录 `plcName` / `verificationInfo` / `selectionBefore` / `selectionAfter` / 说明。接入点：`GoOnline`（含 R/H）、`DownloadToPlc`（含 created 路由与 R/H）、`UploadStationFromPlc`、`UploadDeviceParameters`、`ReadPlcBlockFingerprints`（自带委托里同样应答）。V20 同样有 `TlsVerificationConfiguration`（`Certificates` 仅 V21，未用）。
- **`trustDeviceCertificate`**（`GoOnline` / `DownloadToPlc`，默认 true）：true 等于在 TIA 界面里点"信任"，false 不应答、TIA 拒绝连接（"The device is not trusted"）。上载与指纹工具固定信任并记录。
- **Meta 补齐**：`GoOnline` 响应带 Meta（`success` / `trustDeviceCertificate` / `route` / `tlsVerification` / `error`）；`SetWatchTableModifyValue`、`CheckDownloadReadiness`、`DownloadToPlc`（成功与失败路径）Meta 带 `success`；`ManagePlcSimAdvancedInstance` 的 `data.api` 在动作之后重取（`networkMode` 不再是调用开始时的快照）。
