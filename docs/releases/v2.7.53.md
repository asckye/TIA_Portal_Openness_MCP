## 新增

- **`ManagePlcProtection(devicePathJson, itemPathJson=[], action=read, accessLevel, password, newPassword, confirmChange, dryRun)`**：`read` → `meta.before {accessLevel, masterSecret, accessControl, umcServerAddress}`；`setAccessLevel`（`PlcProtectionAccessLevel` 建模属性，级别高于 FullAccess 时 `meta.note` 提醒还要设 FullAccess 密码）；`setAccessPassword` / `resetAccessPassword`（官方规则：只能给比所选级别宽松的级别设密码，违规时 `meta.warning` 预告 TIA 的拒绝；NoAccess / FullAccessIncludingFailsafe 没有密码）；`protectMasterSecret`（`Protect`）/ `changeMasterSecret`（`ChangePassword`）/ `unprotectMasterSecret`（有密码 `Unprotect(pw)`，否则 `Unprotect()`）/ `resetMasterSecret`（`Reset`，证书丢失）/ `protectAllConfiguration`（V21：有密码 `ProtectAllPlcConfigurationWithPassword`，否则 `ProtectAllPlcConfiguration`）/ `unprotectAllConfiguration`（V21）。改后读回：访问级别逐字比对，master secret 按动作的期望状态集比对（`meta.expectedMasterSecret`）。密码 `SecureString`、不回显、用完释放。
- **`CompileDevice(devicePathJson, itemPathJson=[])`**：`ICompilable.Compile()`，`meta.errors` / `warnings` / `nodes` / 根计数，`success = State != Error`。
- **反射桥参数绑定**：枚举名（不分大小写）与 `SecureString`。
- 形状检查 `HardwareServicesShapeChecks` 第 7 节：两枚举、两个提供者的全部成员、`ICompilable.Compile`、`DeviceItemClassifications.CPU`；V20 报 `MasterSecretConfiguration.WithPasswordAllDataProtection` 与三个 `*AllPlcConfiguration` 为 CAPABILITY。
