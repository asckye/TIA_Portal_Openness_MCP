# v3.1.0 — V20/V21 审计修复及专用工具补齐

本地候选版本，2026-09-30；尚未发布或部署到虚拟机。

新增 10 个工具，静态清单共 474 项，lite 保持 59。完整参数、使用顺序和公开 API 边界见 [补充工具指南](../reference/v20-v21-audit-tools.md)。

- 交叉引用统一拦截反射旁路，扩展变量/系统常量、软件单元和安全单元，遍历失败不再返回成功的部分列表；原生查询默认仍禁用。
- 下载检查读取真实的块/类型一致性；完整下载条件未验证时 `Ready=null`。
- 文档导入只按原生返回名称及准确目标组验证存在性，删除模糊匹配回退；新增软件单元文档操作和可选 SD 导出文本比较。
- 增加补丁/格式限制诊断、原生阶段日志读取及 V20 的 SINUMERIK 归档/报警文本/安全模式、SIMOTION 初始化、SCADA 导出封装。
- lite 工具数由构建生成并校验，修正旧清单中的 56 与源码 59 不一致。
- 完整构建增加两版 STDIO/HTTP、full/lite 混合压力测试门，含 HTTP 8 并发、错误后恢复、交叉引用拒绝与调用日志配对；[测试范围与后续接入](../development/stability-and-integrations-20260930.md)。

验证结果记录在 `manifest/release-build.json`，包括两版编译、离线逻辑、实际 EXE 的保护与失败注入、两版 SDK 成员、HTTP、资源发现、生态和配置器检查。原生工程/选件行为仍需用户指定的测试工程验收；本轮未连接或改动 TIA 工程。

面板类型内部创作和交叉引用索引重建仍没有已核实的纯公开 Openness 实现。西门子产品补丁必须在实际 TIA 安装中确认，SDK 文件版本不是已安装 Hotfix 的证明。
