# v2.7.29

引擎 **2.7.29.0**（V20/V21 均重建）。工具 367、默认 lite 56 项不变。2.7.28 在真实工程（V21 `AutomaticDipCoatingMachine` / `HMI_RT_1`）上重跑暴露了变量导出核对的一处缺陷，本版修复；剩余 WinCC Unified 类型全部登记，[路线图 §2.0](../development/roadmap.md#20-官方-api-全量对齐计划) 阶段 2 收口。

## 修复

`ExchangeUnifiedTags export` 真机恒失败："Native export file missing … `\ShiftModel`"。原因：`HmiTagComposition.Export(DirectoryInfo, name)` 回报的 `FileInfo` 是 `<dir>\<name>`，没有 TIA 实际写出的 `.hmi.yml` 扩展名（脚本模块导出则正确回报 `Name.hmi.yml` + `Name.hmi.js`）。现在 `VerifyNativeFiles` 对不存在的回报路径依次尝试 `.hmi.yml` / `.hmi.js` / `.yml` / `.js` / `.xlsx` / `.xml`，再按 `<name>.*` 同名前缀取第一个非空文件；记录里 `path` 是实际文件，`reportedPath` 保留原生回报，仍要求文件在导出目录内且非空。两条导出工具都新增 `directoryListing`（导出目录里 TIA 留下的全部文件，含 `NameData.yml` / `*.def.hmi.yml` 等原生结果不列出的副文件，最多 500 条）。
