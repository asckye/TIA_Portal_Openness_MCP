# v2.7.23

交付版本 **2.7.23**，引擎沿用已验证的 **2.7.20.0**，应用界面与 2.7.22 相同。本版只修配置器的截图工具。

## 修复：界面截图被裁掉右边和下边

`CapturePage` 按面板的 `ActualWidth/ActualHeight` 建位图，却在面板的外边距偏移处绘制，于是每张截图都少了右侧和底部各 18px——右上角的状态胶囊（“等待配置”）被切掉一截，面板的圆角边框也不见了。位图尺寸现在加上两侧外边距，截图与窗口一致。

只影响 `bin-build/configurator-tests` 下用于界面检查的 PNG，应用本身的布局没有变化（胶囊在窗口里一直是完整的）。
