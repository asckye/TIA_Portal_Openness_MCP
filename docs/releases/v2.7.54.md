## 修复

- **`RunPlcSimAdvancedTestScenario singleStep`**：`PlcSimAdvancedLogic.OperatingModeCandidates("singleStep")` = `SingleStep_CP` → `SingleStep_C` → `SingleStep`，`SetOperatingMode` 取安装 API 定义的第一个并回报 `data.operatingModeApplied`；不认识的模式列出全部 `EOperatingMode` 名。
- **`UploadStationFromPlc` / `ScanAccessibleDevices` 的 `PickPcInterface`**：同名同号的候选视为同一块网卡（工程级提供者按模式重复列出），PN/IE 优先；无参且唯一网卡时同样直接选中；歧义文案带模式名。
- **`GoOnline` 失败**：回报内层异常链、TIA 的 `OnlineProvider.State`（`meta.onlineStateAfter`，`State` 字段用它），`Incompatible` 附"先 DownloadToPlc"提示。
