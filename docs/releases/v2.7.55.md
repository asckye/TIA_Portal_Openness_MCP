## 修复

- **`StepCycles`**（`PlcSimAdvancedChannel`）：先等实例 `Freeze`（模式刚切换时它可能还在跑到第一个同步点），每个周期 `RunToNextSyncPoint()` 后再等 `Freeze`；`PlcSimAdvancedLogic.SyncPointWaitMs` 5000 / `SyncPointPollMs` 2；超时 → 该步 `error` "sync point k of N not reached within …; state …"、`ok=false`；`cyclesStepped` / `waitedMs` / `stateAfterSteps` 进步结果。
- **`OperatingModeCandidates("singleStep")`** = `SingleStep_C` → `SingleStep_CP` → `SingleStep`（手册 "SingleStep operating modes"：`_C` 只在周期控制点冻结，每周期恰好一个同步点）。
