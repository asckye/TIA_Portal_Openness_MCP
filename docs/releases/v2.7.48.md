## crash ⑩ 与守卫

`ScreenComposition.Import` 遇到 Width/Height 与面板不一致的画面抛 `NonRecoverableException "The screen size does not match the device"`，TIA V21 退出。`ImportHmiScreen` 现在先取面板已有画面的 Width/Height，没有画面就从硬件目录描述里解析分辨率（TP700："7\" TFT 显示屏，800 x 480 像素"），不一致或查不到一律拒绝。

## 新增 / 修复

- `ManageOpcUaInterface`：read / delete 服务器接口 / SIMATIC 接口 / 引用命名空间（删掉 2.7.45 假成功留下的空接口 `mcp46_opcua`——它让 `MCP_PLC` 整个编译失败）。
- `ManagePlcSimAdvancedInstance communicationInterface=TCPIP`：实例走 "Siemens PLCSIM Virtual Ethernet Adapter"，`DownloadToPlc` / `GoOnline` 可以安全地对虚拟 PLC 跑（真机上默认已是 TCPIP，`controllerIP 0.0.0.0` 直到首次下载分配 IP）。
- `ImportTechnologyObject` 类型化（反射找错属性名，永远 "TechnologyObjects collection not found"）；`ExportTechnologyObjectsToDirectory` 报数量与失败原因；`WriteClassicHmiMinimalPackageFiles` 尊重 `packageName`；8 处动作校验列出合法值。
