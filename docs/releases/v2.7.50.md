## 修复

- **`SetWatchTableModifyValue` 改官方 SimaticML 往返**：表按组路径（`MCP_W/MCP_WT`）或全树查找（多处同名拒绝，找不到才在根级新建）→ `PlcWatchTable.Export(FileInfo, ExportOptions.None)` → XML 里 `SW.WatchAndForceTables.PlcWatchTableEntry` 行加 / 改（绝对地址 `%M0.0` / `DB1.DBX0.0` 进 `Address`，符号 `"MCP_Start"` / `"DB".Member` 进 `Name`，`ModifyValue` / `ModifyTrigger` / `ModifyIntention=false` / `MonitorTrigger`，ID 取全文档最大十六进制 +1，属性按 TIA 的字母序）→ `group.WatchTables.Import(file, ImportOptions.Override)` → 从新导航读回该行（`meta.after`、`readbackVerified`）。纯 XML 部分在 `WatchTableEntryXml`（离线 12 项测试）。
- **`ManagePlcTableEntries action=deleteTable`**：`PlcWatchTable.Delete()` + 读回缺席（`confirmDelete=true`、`dryRun=false`）。
- **PLCSIM Advanced setter**：属性 → `Set<Name>()` / `set_<Name>()` 方法（类与接口）→ 拒绝信息列出同名成员；`ReadPlcSimAdvancedInstances memberFilter` 列出实例对象匹配的成员。
- **`UploadStationFromPlc`**：扫描到的地址依次在目标接口 / 子网 / PC 接口的 `Addresses` 上 `Create`。
