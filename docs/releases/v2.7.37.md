# v2.7.37

引擎 **2.7.37.0**（V20/V21 均重建）。工具 409 → **413**，默认 lite 清单 56 项不变。本版是"官方 Openness API 全量对齐"计划 [路线图 §2.0](../development/roadmap.md) 的阶段 5：经典 WinCC 文件夹层次——**`Siemens.Engineering.WinCC.dll` 与 `WinCC.Extension.dll` 的功能类型缺口归零，核心程序集（Base / Step7 / 经典 WinCC / WinCC Unified / Safety）全部收口**，只剩选件包（阶段 6，只做形状检查）。

## 新增工具（域 HMI-Classic）

| 工具 | 动作 | 官方入口 |
|---|---|---|
| `ReadClassicHmiScreenTree` | 经典 HMI 的类型化文件夹树：`ScreenSystemFolder` / `ScreenUserFolder`（Screens / Folders）、`ScreenPopupSystemFolder` / `ScreenPopupUserFolder`（ScreenPopups）、`ScreenTemplateSystemFolder` / `ScreenTemplateUserFolder`（ScreenTemplates）、`ScreenSlideinSystemFolder`（`ScreenSlidein` 按 `SlideinType`）、`ScreenOverview` / `ScreenGlobalElements` 存在性；`kind` all / screens / popups / templates / slideins，`folderPath`，递归到 `maxDepth`，每层前 500 个名字 | "Exporting a screen from a screen folder" 系列 |
| `ManageClassicHmiScreenObject` | `objectKind` popup（`ScreenPopup` read / export / delete）、template（`ScreenTemplate` read / export / delete）、slidein（`ScreenSlidein` 按 Top / Bottom / Left / Right：read / export，无原生 Delete）、overview（`ScreenOverview` read / export / import）、globalElements（`ScreenGlobalElements` read / export / import）；`import` 走 `ScreenPopupComposition` / `ScreenTemplateComposition` / `ScreenSlideinComposition.Import` 或 `HmiTarget.ImportScreenOverview / ImportScreenGlobalElements`，回报导入名单；删除与 Override 导入要 `confirmDelete`，删除按 `Find` 核对 | "Exporting / Importing a pop-up screen"、"Exporting / Importing a slide-in screen"、"Exporting screen templates from a folder"、"Deleting a screen template from a folder" |
| `ManageClassicHmiFolder` | 五类用户文件夹的 read / create / delete：screens（`ScreenUserFolder`）、popups（`ScreenPopupUserFolder`）、templates（`ScreenTemplateUserFolder`）、tags（`TagUserFolder`；`TagSystemFolder` 行带 `DefaultTagTable`）、scripts（`VBScriptUserFolder`）；`create` 经类型化 `Folders.Create(newName)` 回读，`delete` 只删空的用户文件夹并按 `Find` 核对，系统文件夹拒绝 | "Creating user-defined folders for HMI tags"、"Deleting a user-defined folder of an HMI device" |
| `ManageClassicHmiGraphic` | V21 `GraphicsProvider` 的多语言图形（`MultiLingualGraphic`）：list / read / export（XML + 旁边的图片文件，默认语言后缀 `default`）/ import（`MultiLingualGraphicComposition.Import`）/ delete；V20 回 NotSupported | "Exporting/importing graphics" |

类型化改造（不改工具签名）：`ReadClassicHmiScripts` / `ManageClassicHmiScript` 的文件夹导航走 `VBScriptSystemFolder` / `VBScriptUserFolderComposition.Find`，`createFolder` 走 `VBScriptUserFolderComposition.Create`，`export` / `delete` 走 `VBScript.Export(FileInfo, ExportOptions)` / `VBScript.Delete()` + `VBScriptComposition.Find` 回读；`ReadLibraryType` 的 `typeKind` 新增 `hmiScreen` / `hmiStyle` / `hmiStyleSheet` / `hmiUdt`（`ScreenLibraryType` / `StyleLibraryType` / `StyleSheetLibraryType` / `HmiUdtLibraryType`）；`EngineeringScalarProperties.Json` 新增引擎侧值渲染钩子——`Siemens.Engineering.WinCC.Extension` 的 `ConstValue`（`{valueClass, value}`）与 `NullableDateTime`（`granularity` = `DateTimeValues`、年月日时分秒可空、`text`）在 V21 上按结构渲染，离线套件里钩子为空。

只在 PublicAPI 上核实的事实：`HmiTarget` 的六个文件夹根都是系统文件夹子类（`ScreenSystemFolder` / `ScreenPopupSystemFolder` / `ScreenSlideinSystemFolder` / `ScreenTemplateSystemFolder` / `TagSystemFolder` / `VBScriptSystemFolder`）；用户文件夹的 `Name` 只读（没有原生改名）；`ScreenSlidein` 没有 Name 与 Delete，只有 `SlideinType` 与 `Export`；`ScreenOverview` / `ScreenGlobalElements` 只有 `Export`，导入在 `HmiTarget` 上；`GraphicsProvider` / `ConstValue` / `NullableDateTime` 仅 V21；`NullableDateTime` 的年月日时分秒是可写的 `Nullable<Int32>`。
