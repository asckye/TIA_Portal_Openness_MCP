# v2.7.43

引擎 **2.7.43.0**（V20/V21 均重建）。工具 447 不变，默认 lite 清单 56 项不变。2.7.42 真机重跑（[v2.7.42 验证](v2.7.42.md#验证)）让 TIA Portal V21 退出三次——CFC 两次、Safety Validation Assistant 一次——引擎三次都活着（2.7.41 的 `legacyUnhandledExceptionPolicy` 首次真机验证）。本版是这三处的守卫。

## 守卫

| 族 | 变化 | 真机依据 |
|---|---|---|
| CFC `ExchangeCfcCharts` / `ManageCfcChartProtection` | `selectiveExport`、`exportInstructionData` 与全部密码动作先做 **`CompleteExport` 预检**：导出到临时 ZIP，解析 `Data.xml` 里带 `Name` 属性的 `*Chart` 元素得到图表清单（`CfcLogic.InspectExport`），`meta.preflight` 回 `chartCount` / `chartNames` / `zipEntries` / `xmlElements`；PLC 没有图表 → InvalidState，图表名不在清单 → NotFound；`skipChartPreflight=true` 跳过（自担风险）；`export` 结果附带 `inventory`。`ManageCfcChartProtection` 新增 `modelVersion`（预检用，默认 V2.0）。两个 csproj 引用 `System.IO.Compression` / `.FileSystem` | `+S1-K1`（1510SP F，装有 CFC 但没有图表文件夹）：`ChartProviderS7` 可取得、`CompleteExport` 写出 484 字节空 ZIP，但 `GetChartProtection("MCP_NONE")` 与 `ExportInstructionData(path)` 各抛 `NonRecoverableException` 并让 TIA 进程消失 |
| Test Suite `RunTestSuiteCase` | `runAll` 对空的系统组回 InvalidState，不再调用执行器 | application 空组 `TestCaseExecutor.Run(ApplicationTestSystemGroup)` 在 TIA 内抛 NullReferenceException（可恢复）；system 空组回 "No test case(s) in the selected project"；样式指南空组回 Success + 2 条消息 |
| Safety Validation `ManageSafetyFunctionCondition` | `create` / `update` 先按信号用途校验 NotRelevant（`SafetyValidationLogic.OwnedInputs`：OperatingMode → executedInput，InputCondition → initialInput + executedInput，Response → response），update 未给 `signalUsage` 时按当前用途校验；写入顺序改为用途 → 输入 → 描述字段；条件级 `checkValidity` 描述标注真机崩溃过一次 | update 写 `ExecutedInput=NotRelevant`（InputCondition）被 TIA 拒绝（"'NotRelevant' is not supported when the signal usage is 'InputCondition'"），但 `Comment` / `SignalName` 已写入；紧接着的条件级 `TestValidity.CheckValidity()` 抛 `NonRecoverableException`，TIA 退出 |
| Safety Validation `ManageSafetyActivationTest changeEvaluationDevice` | 设备改从 `DeviceQuery.EvaluationDevices()` 解析（此前用 `AvailableDevices()`） | `ChangeEvaluationDevice(+S1-7Q1)` 被拒 "'+S1-7Q1' not a valid evaluation device"（可恢复） |

## 兼容性

- `ExchangeCfcCharts` 新增 `skipChartPreflight`（默认 false），`ManageCfcChartProtection` 新增 `modelVersion`（默认 V2.0）与 `skipChartPreflight`；其余签名不变。
- 在有 CFC 图表的 PLC 上，预检多花一次 `CompleteExport` 的时间（大工程按官方建议 32 GB 内存）。
