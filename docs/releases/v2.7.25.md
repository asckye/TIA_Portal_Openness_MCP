# v2.7.25

引擎 **2.7.25.0**（V20/V21 均重建）。工具 359 → **362**，默认 lite 清单 56 项不变。本版是"官方 Openness API 全量对齐"计划的第一步：把 `Siemens.Engineering.Safety` 程序集（V21 XML 12 个类型 / 54 个成员）**全部**封装成专用工具，按官方 "F-related Openness" 章节逐页对照实现。

## 为什么先做 Safety

安全验收（F 集体签名、逐块签名、F 参数、运行组、官方安全打印件）此前只能在 TIA 界面里手工做；程序集小（12 类型）、价值高，且 2.7.24 的覆盖盘点已把它列为 P1。后续按收益排序继续：WinCC Unified（113 个未封装类型）→ Base 硬件深层 → Step7 软件单元/文档 → 经典 WinCC → 选件包，见[路线图 §2.0](../development/roadmap.md#20-官方-api-全量对齐计划)。

## 新增与变更

| 工具 | 变化 | 官方入口 |
|---|---|---|
| `ManagePlcSafety` | **重写为强类型实现**（原为反射）。`read` 现在返回：登录/密码状态；`SafetySettings` 标量 + `AssignmentOfBlockNumbers`（`ManagementMode`、FB/FC/DB 号段）+ `SafetySystemVersion` 与 `GetApplicableSafetySystemVersions()` + 文档化属性 `EnableConsistentUploadFromFCpu` / `EnableFCommunicationIdTag`；运行组标量 + `FOBNumber` / `FOBCycleTime` / `FOBPhaseShift` / `FOBPriority`；**集体 / 软件 / 硬件 / 通信地址 F 签名**（V21 `ProgramSignatures`，2.7.24 之前实际未读出——旧实现把 `SafetySignatureProvider` 当标量对象读，`Signatures` 被归入"复杂属性已排除"）；工程级 `GlobalSettings`；CPU `Failsafe_FCapabilityActivated` 与三个服务的可用性。新增动作：`generateGlobalFIOStatusBlock`、`cleanSystemGeneratedObjects`、`generateBaseId`（V21）、`login` / `logoff` / `setPassword` / `revokePassword`（密码直传 TIA，不记录）；`createRuntimeGroup` 支持三种官方重载（自动生成主安全 FB+IDB / 指定 FC / 指定 FB+IDB）；`updateSettings` 接受嵌套块号段、精确版本字符串与文档化属性；`updateRuntimeGroup` 接受 FOB 属性 | `SafetyAdministration`、`SafetySettings`、`AssignmentOfBlockNumbers`、`SafetySystemVersion`、`RuntimeGroup(Composition)`、`SafetyBaseIdProvider` |
| `ManageSafetyGlobalSettings`（新） | TIA Portal 级 `GlobalSettings` 读/改：`SafetyModificationsPossible`、`GenerationOfDefaultFailsafeProgram`、`ManagementOfFailsafeInSoftwareUnitsEnvironment`、`UsernameForFChangeHistory`（超过 256 字符拒绝而不是让 TIA 静默截断） | `GlobalSettings` |
| `ReadSafetyBlockSignatures`（新） | 逐块 F 签名：单块或整个 PLC 递归；无 `SafetySignatureProvider` 的块计数不列出；值 0 = 无有效签名；可同时返回 PLC 级集体签名 | `SafetySignatureProvider`、`SafetySignature(Type)` |
| `ExportSafetyPrintout`（新） | 官方安全打印件写文件：`MicrosoftPrintToPdf`(.pdf) / `MicrosoftXpsDocumentWriter`(.xps/.oxps)，`All` / `Compact`，版式默认 `DocuInfo_ISO_A4_Portrait`；拒绝覆盖已有文件；返回原生 bool、字节数与 SHA-256 | `SafetyPrintout.Print` |
| 下载提示 | `Safety.Download.Configurations.SafetyProgram` 应答其唯一选项 `ConsistentDownload` | `SafetyProgramSelections` |

安全门槛：全部写入默认 `dryRun=true`；改程序的动作要求 Offline，且密码保护时必须已登录（可用 `action=login`）；`deleteRuntimeGroup`、`generateGlobalFIOStatusBlock`、`cleanSystemGeneratedObjects`、`generateBaseId`、`setPassword`、`revokePassword` 与 `SafetyModeCanBeDisabled` 额外要求 `confirmSafetyChange=true`。CPU 的 `Failsafe_FCapabilityActivated` 是普通硬件属性，经已有的 `SetDeviceItemAttribute` 修改（关闭会删除安全程序，本版只读它）。

V20 差异：`SafetyAdministration.ProgramSignatures`、`SafetyBaseIdProvider` 以及 `SafetySignatureType` 的集体/软件/硬件/通信地址四个值都是 V21 API；V20 上集体签名返回 `null` 并附说明、`generateBaseId` 返回 `NotSupportedOnVersion`，逐块签名两版都有。

未封装：`SafetyValidation`（安全验证助手，14 类型，独立选件）留待选件包阶段。**F 编译不在 PublicAPI 内**，签名只在 TIA 内 F 编译后更新；本版不改变"API 可用 ≠ 功能安全验收"。
