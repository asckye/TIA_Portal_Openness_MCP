# v2.7.22

交付版本 **2.7.22**，引擎沿用已验证的 **2.7.20.0**（运行文件与工具清单未改动）。本版只调整 2.7.21 配置器右栏的高度行为。

## 配置器：AI 客户端栏在卡内滚动

11 张客户端卡片在 2.7.21 里会把 B 栏撑高，左侧 A 栏被迫留出约 145px 空白。现在：

- B 栏的卡片区限高到三行并在**卡内上下滚动**，滚动条为与整体配色一致的细条；
- A、B 两栏改为底部对齐的布局，按钮行固定在卡片底部，多余空间落在分隔线之上，两栏等高且视觉一致；
- 两种模式都适用：同一台电脑模式下 A 栏较高时，B 栏的卡片区仍保持三行，不再随之拉伸。

卡片内容、顺序、写入位置与其余交互没有变化。
