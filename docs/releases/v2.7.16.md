# v2.7.16

完整运行包：**TIA_MCP_Delivery_v2.7.16_20260917.zip**。解压后双击根目录 `TiaMcpConfigurator.exe`，即可配置虚拟机服务、宿主机 AI 客户端或本机连接。

- 新增 WPF 配置界面：深色侧栏、浅色卡片、三页导航、客户端多选、密钥显示切换和运行日志。
- 支持 Claude Code、Claude Desktop、Codex、Cursor、VS Code、Gemini CLI、Windsurf、Cline。按各客户端格式合并配置并备份；Claude Desktop Chat 远程连接通过 mcp-remote 桥接，需要 Node.js。
- 服务端支持 V20/V21、安装路径、IPv4/端口、密钥生成与 Windows 用户加密保存、网络权限配置、启动和停止。启动前检查监听权限和端口占用。
- 删除已被 GUI 替代的 `配置MCP.bat`、`配置MCP-v20.bat`、`tia.cmd`、`tia-v20.cmd`。命令行仍可直接调用 `runtime/v21/TiaMcpServer.exe` 或 V20 对应程序；工程生成、预热和取证脚本保留。

**版本组成：交付包及配置器为 2.7.16，V20/V21 引擎沿用 2.7.15.0。** 引擎源码和二进制没有修改；原始构建记录、测试日期及哈希完整保留在 `manifest/release-build.json`。新 GUI 的独立构建与测试记录见 `manifest/configurator-build.json`，交付组成及构建记录哈希见 `manifest/delivery.json`。完整 ZIP 包含两版运行依赖、手册、模板、源码、测试和许可证，不需要旧包补文件，不包含 Siemens PublicAPI 或个人密钥。

本次配置器通过 **53 项隔离测试**，覆盖 8 个客户端的配置格式、合并备份、密钥保护、HTTP 检查和 WPF 窗口渲染；交付校验核对 GUI、引擎及源码哈希。原引擎 708 项离线测试及两版程序集回归是 2.7.15 的既有结果，未冒充本次重新编译验收。
