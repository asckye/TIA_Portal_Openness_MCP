# v2.7.46

引擎 **2.7.46.0**（V20/V21 均重建）。工具 447 不变，默认 lite 清单 56 项不变。维护者的要求是"把之前没测过的接口全部重测一遍，不能遗留问题"——本版就是这一轮全量真机重测的产物：在空工程 `项目1` 里用引擎自建的 1515F-2 PN、TP700 Comfort、MTP700 Unified Comfort、S120（含驱动轴 / 电机 / 编码器）把 **447 个工具各跑了一遍**，逐工具结论在[真机台账](../reference/real-machine-ledger.md)。

## 真机结果

见[真机台账](../reference/real-machine-ledger.md)（按域分表，每个工具一行：通过 / 手工单跑 / 早期真机 / 本版修复待重跑 / TIA 或环境拒绝 / 只到参数拒绝 / 刻意不跑 / 未跑）。要点：

- PLC-Software、Hardware、HMI-Classic、HMI-Unified、Library、Project、Security、VersionControl、Safety、Startdrive / DCC、Simulation（PLCSIM Advanced 实例 register / powerOn / read / powerOff / unregister）全部走通。
- 只读 S7 协议工具（`ProbeS7CpuIdentity` / `GetPlcRunStateS7` / `ReadPlcLiveValuesS7` / `SamplePlcLiveValuesS7` / `MonitorWatchTableLiveS7`）在虚拟机网段的 192.168.0.1 上读到一台 **CPU 1510SP F（RUN）**——那是维护者的真实 CPU，所以 `GoOnline` / `DownloadToPlc` / 上传类工具刻意没跑。
- 两个新的 TIA 退出点：⑧ WinCC Unified 面板 `/20.0.0.0` 标识、⑨ `TO_PositioningAxis 6.0` 的 Create。
- 会话级往返（`CloseProject` → `OpenProject(path)` → `Disconnect` → `Connect` → `AttachToOpenProject`）通过。
