# v2.7.21

交付版本 **2.7.21**，引擎沿用已验证的 **2.7.20.0**（V20/V21 运行文件与工具清单均未改动，仍是 359 工具 / 默认 lite 56 项）。本版只重做 `TiaMcpConfigurator.exe` 的界面。

## 配置器：单页双栏连接控制台

原来的深色编号侧栏 + 三页（虚拟机服务端 / AI 客户端 / 本机连接）改为**一页两栏**，右上角用分段开关切换两种模式：

| | 虚拟机 ↔ 宿主机 | 同一台电脑 |
|---|---|---|
| 传输 | HTTP | stdio |
| A 栏 | 版本、安装目录、VM IPv4、端口；网络权限 / 停止 / 启动服务 | 版本、安装目录；固定 `stdio · 客户端按需自动启动引擎` |
| B 栏 | 客户端卡片；测试连接 / 写入客户端配置 | 客户端卡片；写入客户端配置 |
| 密钥条 | A / B 共用一把密钥 | 隐藏（stdio 不需要密钥） |

- **连线条**：两栏之间实时显示 `客户端侧 → 端点 → 服务侧`，端点为 `IP:端口` 或 `stdio · 无需网络`，状态为 `idle` / `running` / `local`，服务侧跟随所选 TIA 版本。
- **共用密钥**：原来服务端页和客户端页各有一份地址/端口/密钥，现在合并为一组字段和一条 `SHARED SECRET` 密钥条，不会再出现两页填了不同值的情况。新增 **保存两端配置**：客户端侧连接信息总能保存；服务端配置只在本机确实装了 TIA 和引擎时写入，宿主机上校验失败只记一行日志，不再当作错误弹窗。
- **运行日志**：改为带 `ACTIVITY LOG` 标题和条目计数的卡片；状态灯并入右上角状态胶囊。
- **视觉**：米白底 + 白卡 + 墨绿强调色（原为蓝色），等宽字体标签，卡片圆角与分段开关按参考稿实现。窗口缩小时客户端卡片由三列变两列。

界面之外的行为没有变化：客户端卡片仍是同一批 11 张、写入位置和条目格式不变，服务器名仍为远程 `tia-portal-vm` / 本机 `tia-portal`，网络权限、启动/停止、测试连接、备份与密钥加密逻辑均照旧。
