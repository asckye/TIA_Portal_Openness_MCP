# v2.7.18

引擎 **2.7.18.0**，V20/V21 均在本机 PublicAPI 上重建；交付版本与引擎版本重新一致。工具 298 → **350**，默认 lite 56 项，其余经 `FindTools` + `CallTool`。本版没有连接真实 TIA 工程或在线 PLC；全部新工具按官方程序集 API 形状与离线逻辑验证。

## 修复

- `DownloadToPlc` 的下载提示应答。此前 `UserManagementDownload`、`AlarmTextLibrariesDownload`、`DownloadCertificate` 三个选择型提示被当作复选框调用 `Checked`（该属性不存在，静默无操作），另有 27 种提示类型从未处理。现在委托用反射识别每个提示的真实形态并按 `DownloadPromptPolicy` 应答；未能应答的提示连同 TIA 的提示文本回传在 `Meta.promptsUnanswered`，失败信息中列出类型名。破坏性提示（`ResetModule`、`InitializeMemory`、`OverwriteOnMemoryCard`、`OverwriteSystemData`、`SwitchBackupToPrimary`、`ProtectionLevelChanged`）默认不动，需经 `promptAnswersJson` 显式指定；密码类提示只接受专用参数，绝不进入 JSON 或日志。

## 分类

引擎内 `ToolTaxonomy` 是分类的唯一事实来源：7 个大类（`session`、`project`、`plc`、`plc-online`、`hardware`、`hmi`、`runtime`）、26 个域标签、8 种规范操作类型；描述未标注操作类型的工具按名称推断并在矩阵中以 `*` 标记。[工具矩阵](../reference/tool-matrix.md) 改由 `manifest/tools-list.json` 按大类→域生成，随 `Build-Release.ps1` 自动刷新。
