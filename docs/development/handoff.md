## Current source

All eight releases use FoundationHost and one PlcWorker per MCP session ([ADR 0005](decisions/0005-v20-v21-on-foundation-host.md), [ADR 0007](decisions/0007-one-worker-per-mcp-session.md)). The MCP entry is `runtime/v<key>/TiaMcp.FoundationHost.exe --release-key <key>`, and the worker is `runtime/v<key>/worker/TiaMcp.PlcWorker.<key>.exe`. Since P8-04j2 (`62ebf86e`), V20/V21 run on the PlcWorker by default; its owner thread is MTA on V20/V21 and STA on V14 SP1–V19 (`src/Adapters/Policy/PlcLifecyclePolicy.cs`). The package no longer contains `TiaMcp.Engine.V20.exe`, `TiaMcp.Engine.V21.exe`, their worker files or `tool-catalog.json`, and the packaged no-TIA answers on V20/V21 are unchanged from the engine. The engine is built only as a private compatibility copy under `bin-build/engine-compat` for the repository cross-checks until P8-04l deletes it. The host refuses the `--engine-*` options with exit code 64 unless a repository check selects that private copy (`src/FoundationHost/HostOptions.cs`). The release record is `manifest/multi-version-build.json` with an `engineCompatibility` section (P8-04j1b `38ca2883`); `manifest/release-build.json` is no longer delivered. The host command-line subset (`doctor`, `audit verify`, `schema`, `version`, `config`, `install-plc-tools`, `help`) runs on FoundationHost for all eight releases (P8-04i `a027cf08`); the engine verbs `gen`, `patch`, `describe`, `compile`, `export`, `import` and `prewarm` are retired. The engine MCP host and its isolation switches are retired. All releases share category-based timeout budgets (`3bfd5806`; [ADR 0008](decisions/0008-worker-timeouts-and-faults.md)).

P8-stab-1 (`44f4aa3c`) fixed three worker-lifecycle races behind intermittent foundation failures: `WorkerShutdown.KillOwned` treats a child that exited during the image probe as stopped; the Foundation approval window opens just before the wait, after the apply precheck; a staging list cut at 200 batches carries an `INCOMPLETE_DATA` warning instead of failing. P8-91 (20 consecutive clean runs on master) is in progress.

All 35 port families (batches B1–B12) are merged and their V20/V21 engine implementations are deleted. The API recheck (`ee2482ac`) determines whole-tool and action availability. The 2026-10-19 official-API audit is fixed in batches: P8-81a `6b8cf3e8`, P8-81b `ac5e9eac` and P8-81c `c89b7c20` are merged, and P8-81d–g are pending. Shared implementations take the audited ToolMetadata classification on all eight releases, including batch admission (`9e7e3f57`). P8-82 (`c2b4af38`) opened 47 reviewed read tools for read-only batches and closed two, and P8-82d (`b920ff46`) documents the rule in the protocol specification; the review is in `bin-build/refactor/batch-flag-review.md` of the maintainer checkout.
