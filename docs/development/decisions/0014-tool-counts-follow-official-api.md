# 0014 各版本的工具数量按官方 API 支持决定，不为一致而拉平

- 状态：已采纳
- 日期：2026-10-10
- 决策者：维护者
- 置信度：高
- 相关：[ADR 0012](0012-old-release-tool-registration.md)；[阶段 8 迁移方案](../phase8-port-plan.md)；[官方 API 覆盖与逐版缺口](../../reference/openness-coverage.md)；[重构计划](../refactor-plan.md) P8-04；[文档偏差清单](../design-spec/deviations/docs.md) DOC-02

回溯记录（写于 2026-10-11）。此前仓库内没有本决定的书面记录。

## 背景

ADR 0012 之后，八个版本的工具数量各不相同。一种看法是为了一致，应当把旧版的工具补齐，或者把新版的工具裁掉。另外，有些工具在旧版关闭，只是因为当时只有 V20/V21 的格式证据。

## 选项

1. 拉平数量：目录看起来一致；要么在旧版发布不能运行的工具，要么在新版隐藏可用的能力。
2. 按官方 API 支持决定数量，并复查只因证据不足而在旧版关闭的工具。

## 决定

采用选项 2。各版本的工具数量按官方 API 支持决定，不为一致而拉平；只因缺少 V20/V21 以外的格式证据而在旧版关闭的工具，在 P8-04 中按官方文档与 API 复查，支持的就开放。

## 后果

- 正面：每个版本的目录如实反映该版的能力。
- 负面与取舍：文档不能写统一的工具数量；数量由生成器写入，手写文档只链接生成目录（DOC-02，P8-63）。
- 后续工作：P8-04 的复查。
- 验证方式：生成的工具目录与契约快照；P8-04 的复查记录。
