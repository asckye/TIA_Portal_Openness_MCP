# 0018 工作台界面采用 Ant Design v5 的视觉规范和布局

- 状态：已采纳
- 日期：2026-10-18
- 决策者：维护者
- 置信度：高
- 相关：[ADR 0015](0015-microsoft-design-spec-baseline.md)（视觉部分被本决定取代）；[工作台界面设计规范](../design-spec/workbench-ui.md)；[工作台偏差清单](../design-spec/deviations/workbench.md) C.0；[重构计划](../refactor-plan.md) P8-80

## 背景

工作台（WPF）原来按 Primer/Fluent 风格自绘控件，页面按顶部页签切换，工程概览和程序块分在两页。维护者要求界面改用 Ant Design 的规范和组件风格，并要求工程概览和程序块放在同一页。Ant Design 没有官方 WPF 组件库。

## 选项

1. 改用 Web 技术（WebView2 + antd）重写界面：组件现成；但要重做全部视图、绑定和 UI 测试，4.0 前风险过大。
2. 保留 WPF，视觉层按 Ant Design v5 的 token 和组件规范重画，布局按 Ant 的 Layout（侧边菜单 + 顶栏 + 内容区）重排；视图模型、命令和工具调用不变。

## 决定

采用选项 2。

- 颜色、圆角、间距和组件样式取自 Ant Design v5。正文和按钮的主色用 blue-7 #0958D9（深色 #3C89E8），以满足 WCAG 2.2 AA 的 4.5:1 对比度；#1677FF 只用于图形。深色背景用 #000000，警告徽标底色用 #FFFBE6。高对比模式继续跟随 Windows 系统颜色。
- 布局：左侧分组菜单（216 epx；窗口宽度低于 992 epx 时收成 56 epx 图标栏），56 epx 顶栏（面包屑、MCP 状态、连接标签、待批、诊断、语言），内容区统一用页头加卡片。“项目”页把工程概览和程序块合为一页：左边是程序块表格，勾选后出现批量操作条；右边是编译、检查、环境体检和日志卡片。
- 对话框按钮按显示顺序排列，确认按钮在右，Tab 和读屏顺序与显示顺序一致。

## 后果

- 正面：界面风格统一，常用操作集中在“项目”页；无障碍要求（WCAG 2.2 AA、UIA 名称、焦点、访问键）保持不变。
- 负面与取舍：控件仍是自绘，Ant 的新组件需要逐个按规范实现。部分测试断言钉住了旧布局的尺寸和文字，维护者已批准按新布局更新；对比度、焦点、最小点击尺寸等策略检查不变。
- 后续工作：MCP 页第 3 步（客户端已写入）还没有可读的状态；设置仍以抽屉方式打开。
- 验证方式：Studio GUI、Core 与配置测试（两种共享适配器模式），渲染与截图测试，`ThemeSurfaceTests` 固定 60 个颜色 token。
