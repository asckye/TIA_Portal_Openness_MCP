## 实现

- 新增 `ConnectToProject(processId, processStartUtc, projectPath)`；连接时记录主版本、PID、启动时间、规范化工程完整路径、名称与绑定代次。项目访问拒绝身份变化；按名连接拒绝多实例歧义，`GetState` 不再自动换绑。
- 新增同 Windows 用户的 TIA 会话独占租约。新版本 MCP 的其他进程在 Attach 前被拒绝；干净断开可复用，异常退出标记保留至 TIA 重启。它不约束旧版 MCP、其他 Openness 软件、其他 Windows 用户或手动 UI，也不是同实例共享队列。同一 MCP 服务的多个客户端仍共享该服务会话，不能当作独立工程会话使用。
- 批量预览令牌纳入完整工程身份；HMI 事件、脚本、运行设置的内容令牌同时绑定进程及绑定代次，重新绑定后必须重新预览。
- 新增 [DeleteHmiTag](../guides/hmi/delete-tag.md)，支持 Classic/Unified 普通 HMI 变量，默认预览、实际删除需确认标志，删除一次后验证不存在。不查交叉引用，不自动保存、编译或下载，不声称变量未被使用。
- 日志增加缓存绑定、线程、公寓模型和可提供的对象类型/路径；`GetState` 报告日志写入失败计数。加入只读 Windows 事件、近期调用日志和转储路径证据收集器；不会读取转储内容、上传或修改系统转储设置。
- 新增[原生 MCP 会话验收脚本](native-mcp-session-tests.md)，默认只生成计划；本次仅运行离线安全检查。
