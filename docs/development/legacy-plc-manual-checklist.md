## publicationReview

- **status**: source/offline closed for all eight exact compile targets; native acceptance NOT RUN
- **implementation**: All block/type/tag-table Export callbacks write only to an independent sibling staging directory. Validate nonempty regular Openness XML with DTD disabled and size bound, hash under read lock, then same-volume two-argument File.Move without overwrite. No copy/delete/retry fallback.
- **failure**: Retain stage and any partial output; worker exposes only destination/staged paths, recovery directory, phase and SHA256. Fixed public error message excludes native exception contents. Successful publication preserves unexpected sidecars and returns recovery directory.
- **tests**: Real Windows filesystem: existing target, target created during export, two concurrent publishers, competing directory, callback exception with secret text, partial/missing/empty/malformed/wrong-root/DTD output, successful cleanup and retained sidecar. No Siemens execution.
- **limits**: Native export/file-lock interaction remains untested. Same-volume publication does not establish native runtime support or protect against a hostile actor replacing directories/reparse points.
