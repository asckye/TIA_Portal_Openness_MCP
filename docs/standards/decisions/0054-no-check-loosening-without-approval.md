# 0054 不删除、跳过、过滤或放宽任何检查，除非维护者批准

- 状态：已采纳
- 日期：2026-10-10
- 决策者：维护者
- 置信度：高
- 相关：[AGENTS.md](../../../AGENTS.md)“范围”；[ADR 0043](0043-recording-maintainer-approvals.md)（批准记录的边界，不取代本决定）；[验证](../../manuals/validation.md)；提交 `59731d947`、`3a2276574`

回溯记录（写于 2026-11-25，待补写编号 B36）。

## 背景

做出此决定的原因没有记录。

## 选项

没有记录其他选项。

## 决定

- 不删除、跳过、过滤、放宽或重设任何功能检查、测试、断言、阈值和门禁，含套件最低通过数、最大跳过数、计时与增长上限；认为检查有误或不稳定时保持原样，在报告中附证据，由维护者决定。
- 2026-10-11 补充：功能按设计有意改变时，可用仓库内正式工具重新生成受影响的生成基线和 golden 文件，在报告中逐项列出差异；改阈值、改断言、删除或跳过检查仍须维护者批准。

## 后果

- 正面：检查的强度只能经维护者决定降低。
- 负面与取舍：误报的检查也要等维护者批准。
- 后续变化：REVIEW-PORT 以 `check-loosening` 在合并门中执行；维护者批准移除的范围列在[验证](../../manuals/validation.md#已批准移除的检查机制)；批准记录的规则见 ADR 0043。
- 验证方式：`check-loosening` 对比 merge-base 与工作树，命中项须有批准记录。
