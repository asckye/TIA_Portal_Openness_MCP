# 0039 GitHub 仓库改名为 automation-engineering-workbench，旧名永不再用

- 状态：已采纳
- 日期：2026-11-22
- 决策者：维护者
- 置信度：高
- 相关：[开发计划](../../plan/plan.md) RENAME-GH；[发布流程](../../manuals/release.md)；产品更名决定（2026-10-30）

## 背景

产品对外名称已是“自动化工程工作台 / Automation Engineering Workbench”，GitHub 仓库仍以产品旧名 TIA Portal Openness MCP 命名（单词以下划线连接，下称旧名）。维护者 2026-11-21 决定 rc.1 不改名，改名排在 rc.2 或正式版之前。2026-11-22 rc.1 发布后执行改名（RENAME-GH）。

已安装的 3.3 和 beta 更新器把旧仓库地址写在程序中，经 GitHub 的重定向读取发布。如果有人用旧名新建仓库，重定向立即失效，旧更新器会读不到发布，或读到新仓库发布的内容。

## 选项

1. 保持旧名：没有风险；仓库名与产品名长期不一致。
2. 改名并依赖 GitHub 重定向，规定旧名永不再用：名称一致；重定向依赖旧名一直空着。

## 决定

采用选项 2。仓库改名为 `asckye/automation-engineering-workbench`，README、NOTICE、插件、更新检查和发布工具中的有效地址同步改为新名。可执行文件 `TiaMcp.*`、安装包名、插件 ID 和 MCP 服务名 `tia-portal` 不变。

旧名永不再用于 `asckye/` 下的新仓库、复刻或改名目标，以保留 GitHub 的重定向。仓库检查禁止现行文档写出旧名全称，本 ADR 因此只描述它。已发布的说明和历史记录中的旧地址不改写。

## 后果

- 正面：仓库名与产品名一致；旧网址、克隆地址和 API 地址经重定向继续可用。
- 负面与取舍：3.3 更新器读取发布页时不跟随重定向，GitHub API 限流时可能读不到最新版本，稍后重试即可。
- 后续工作：[发布流程](../../manuals/release.md)的准备环境一节写明这条规则。
- 验证方式：发布前检查有效引用使用新名；更新器测试覆盖 API 地址允许列表（LOW-RC2C）。
