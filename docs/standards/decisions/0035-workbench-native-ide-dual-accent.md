# 0035 工作台采用原生桌面 IDE 布局与双强调色工程色板

- 状态：已采纳；外框、页面布局与部分配色由 [ADR 0036](0036-workbench-final-ide-layout.md) 取代；HTTP 密钥与保管库的移除由 [ADR 0038](0038-keyless-http-transport.md) 单独记录
- 日期：2026-11-19
- 决策者：维护者
- 置信度：高
- 相关：取代 [ADR 0028](0028-workbench-visual-design-eplanmcp.md) 的视觉配色、主题选项与窗口外框部分；保留 [ADR 0003](0003-workbench-approval-for-mcp-writes.md) 及[工作台界面规范](../ui.md) §5 的审批与 AI 控制红线（含物理 PLC 破坏性操作的双重确认与 Enter 拦截）

## 背景

ADR 0028 确立了工作台的基础设计令牌与无障碍底线，但在面向 TIA Portal 工业自动化工程师的实际使用中，原有布局与视觉存在以下摩擦：

1. **中性色与层次**：原有浅色/深色中性灰偏暖且层级对比偏弱；深色 `bg-grouped` 仍使用 `#000000` 纯黑，在工控高密度界面中容易产生眩光与割裂。
2. **强调色与品牌认同**：单一 Apple 蓝（`#0071E3`）难以同时满足偏现代 IDE 审美（精密钴蓝）与西门子 TIA 工程工具审美（西门子青碧）。
3. **主题选择精简**：维护者决定在界面中只保留“浅色”与“深色”两个显式主题，不再提供“跟随系统（自动）”选项；Windows 系统高对比主题仍由 `ThemeManager` 自动感知并覆盖，不在设置页提供手动开关。
4. **桌面 IDE 布局与归属**：
   - 运行日志页右侧 320 epx 卡片栏长期占据近三分之一宽度，压缩了高密度日志流的横向空间；其中“轮转与保留”“日志目录”及常驻诊断包卡片属于低频设置/运维配置，应收敛至 `设置 › 服务与存储`，让日志流恢复 100% 全宽显示，并在工具栏保留轻量“生成诊断包”触发入口与按需进度条。
   - HTTP MCP 共享密钥（SEC-05）与本地 DPAPI 凭据保险库（SEC-16）已从产品移除，局域网 HTTP 改回免密直连，对应配置区与安全设置区同步精简。
   - 写操作审批总开关改为直接切换，不再强制输入确认词；物理 PLC 下载与破坏性写入的双重确认面板与 Enter 拦截红线完整保留。

## 选项

1. 仅微调旧色板，保留 64 epx 顶栏、320 epx 日志右侧栏及“自动”主题选项：改动量小，但日志空间浪费与原生 IDE 一体化问题未解决。
2. 全面升级为原生桌面 IDE 工作台外框 + 冷调浅色 / 午夜板岩深色 + 精密钴蓝与西门子青碧双强调色 + 全宽日志与设置收敛：保留全部无障碍（WCAG 2.2 AA）与物理 PLC 安全红线，显著提升工业工程工具的阅读密度与视觉一致性。

## 决定

采用选项 2，并确立以下设计基线：

1. **两套明暗主题（无“自动”选项）**：
   - **冷调浅色（Cool Crisp Light）**：纯冷中性灰阶（窗体 `#FFFFFF`、分组底 `#F1F5F9`、卡片 `#FFFFFF`、标题栏 `#F8FAFC`、侧边栏 `#F1F5F9`、状态栏 `#E2E8F0`），零暖色/米色偏移。
   - **午夜板岩深色（Midnight-Slate Dark）**：冷蓝灰板岩阶梯（窗体 `#0B0F15`、分组底 `#101620`、卡片 `#141B26`、标题栏 `#0D121A`、侧边栏 `#0D121A`、状态栏 `#090D12`），全界面零 `#000000`。
   - 系统高对比（`SystemParameters.HighContrast`）仍自动优先接管，使用 `Palette.HighContrast.xaml` 的 `SystemColors` 配对。
   - `UiSettings` 中旧的 `theme=Auto` 读取时回落为 `AppTheme.Light`。
2. **双品牌强调色（同步支持、持久化保存）**：
   - **精密钴蓝（`AppAccent.Cobalt`）**：主强调 `#2563EB`，悬停 `#1D4ED8`，浅色文字/链接 `#1D4ED8`，深色文字/链接 `#60A5FA`（所有白底/实底对比度均满足 WCAG 2.2 AA ≥ 4.5:1）。
   - **西门子青碧（`AppAccent.Petrol`）**：主强调 `#0E7C86`，悬停 `#0B656E`，浅色文字/链接 `#0B656E`，深色文字/链接 `#2DD4BF`。
   - 四组常规调色板（`Light`/`Dark` × `Cobalt`/`Petrol`）与 `HighContrast` 共享完全一致的语义资源键（含 `Primer.titlebar`、`Primer.rail`、`Primer.statusBar`、`Primer.accentSoft`、`Primer.accentRing` 及 PLC 块类型徽标令牌 `Primer.blkOb/Fb/Fc/Db/Fs`），并全部纳入 `ThemeSurfaceTests` 与 `AccessibilityTests` 的 WCAG 2.2 AA 自动化校验。
   - 在 `设置 › 外观` 中同时提供明暗主题与强调色选择，通过 `UiSettings.Accent` 持久化并支持 `--accent` 命令行参数。
3. **原生桌面 IDE 外框与功能归位**：
   - 统一顶部纤细标题区、带左侧 `3 × 16 epx` 选中指示条的导航栏、以及底部 28 epx 原生 IDE 状态栏（集中展示 MCP 服务、TIA 会话状态与写操作审批状态）。
   - 各内容页顶部采用统一高度的工具栏地平线与轻量胶囊筛选控件，消除多层冗余标题头。
   - **运行日志全宽化**：移除 `LogView` 右侧 320 epx 固定栏，日志列表占满 100% 宽度；在工具栏保留“生成诊断包”按钮及按需展开的进度/结果条；将“轮转与保留”“日志目录”及诊断包常驻管理收纳至 `设置 › 服务`。
   - **安全与审批**：移除 SEC-05 密钥与 SEC-16 凭据保险库界面；写操作审批开关允许人直接切换，不再要求输入确认词；物理 PLC 下载/删除等破坏性确认面板及其 Enter 键安全拦截保持不变。

## 后果

- **正面**：所有常规主题与双强调色均通过自动化 WCAG 2.2 AA 对比度校验；日志流可读宽度提升约 35%；页面信息密度与原生桌面工程工具高度一致；两套强调色满足不同工程师偏好。
- **权衡**：4 套常规调色板与 1 套高对比调色板须保持资源键严格同步（由 `ThemeSurfaceTests` 守护）；部分旧布局与 `CONFIRM` 确认弹窗的 GUI 单元测试需按新决定同步更新。

- 2026-11-23：HTTP 共享密钥与 DPAPI 凭据保管库的移除由 [ADR 0038](0038-keyless-http-transport.md) 单独记录，含选项、接受的风险与缓解措施。
