# 0044 MCP 可见文本一律英文，响应不做本地化，错误用稳定错误码

回溯记录（写于 2026-11-25，待补写编号 B02）。

## 背景

当时 V21 的 488 条工具描述中 482 条为纯英文，其余 6 条只在引用 TIA 原文或示例名称时含中文；引擎与 Logic 约有 100 条消息含中文。部分文本承担功能，例如枚举拒绝文本被解析、检查脚本按消息判断。

## 选项

1. 为 MCP 响应加本地化层：调用方是 AI，本地化会破坏快照与确定性，被排除。
2. MCP 文本只用英文，本地化留在人看的界面。

选择英文而不是中文作为统一语言的原因没有记录。

## 决定

采用选项 2：

- 新增的 MCP 可见文本一律英文；中文只作为数据出现，例如 TIA 原文和示例名称。
- 重构阶段 0–5 冻结既有文本，阶段 6（4.0）统一为英文，提供旧到新的对照表。
- MCP 响应不做本地化；本地化只在工作台和命令行 `doctor` 输出中进行。
- 4.0 起错误使用稳定错误码，文本不再承担功能。

## 后果

- 正面：快照和契约结果确定；改措辞不改变行为。
- 负面与取舍：中文用户看到的 MCP 消息是英文。
- 落实：`7d3651c32`（2026-10-05）使第一方 MCP 文本全部为英文，并由类型化元数据和错误码代替对消息文本的判断。
- 验证方式：设计规范第 6.2 节的 MUST；八版契约基线。
