# 0036 工作台最终 IDE 布局

- 状态：已采纳
- 日期：2026-11-20
- 决策者：维护者
- 相关：在 [ADR 0035](0035-workbench-native-ide-dual-accent.md) 基础上细化布局与页面结构；保留 [ADR 0003](0003-workbench-approval-for-mcp-writes.md)、[ADR 0028](0028-workbench-visual-design-eplanmcp.md) 中审批同等权重与危险确认的规定，以及[工作台界面规范](../ui.md) §5 的审批与 AI 控制红线

## 背景

维护者提供了最终设计稿（`bin-build/design/workbench-final-design.html`，不随发布分发）：38 epx 标题栏居中 Ctrl+K 命令面板、60 epx 图标加短标签的活动栏、左侧工程树或上下文列表、26 epx 状态栏、会话弹出层，以及合并后的页面结构。设计稿中有几处与审批红线冲突，另有几处功能没有宿主数据支撑。

## 决定

1. 采用设计稿的外框、页面集合与尺寸：标题栏 38、活动栏 60（不再折叠）、左侧面板 262（设置 236）、页面工具栏 44、筛选条 38、状态栏最小高度 26、动效 120 ms、遮罩 30%/68%。页面为：项目、Agent（审批与 AI 调用）、MCP、客户端、环境诊断、审计、日志，以及设置；快捷键 Ctrl+1…7 按此顺序，新增 Ctrl+K 打开命令面板。版本控制并入项目树。内部页面标识 Approvals、Calls、VersionControl 保持不变，AI 控制白名单不变。
2. 审批红线不变：状态栏只显示写操作审批状态，点击跳转「设置 › AI 控制」，不提供一键开关；批准与拒绝保持同等外观与 44 epx 高度，均不是默认按钮；危险确认保持取消为默认、Enter 不确认、确认按钮有访问键；倒计时圆环保留；客户端名称保留“（未验证）”。
3. 颜色以现有调色板为准，只采纳设计稿中通过 WCAG 2.2 AA 的值；设计稿暗色强调填充与三级文字未通过对比度的不采用。暗色强调文字保留 ADR 0035 的值。所有新键同时映射到高对比调色板。
4. 暂不实现、留待后续任务：块 SCL 代码视图（每次查看需导出文件）、审批卡中的 AI 改动差异与设备事实（需要宿主提供数据）、版本控制“提交”、日志行 JSON 字段展开、变量表 CSV 导出。
5. 项目树保留块复选框，作为导出与导入的选择和 AI 预填的目标。会话弹出层不显示原生交叉引用开关（2026-11-20 起八版默认启用，开关已取消）。提示条保留右下角位置和关闭按钮。调用详情在宽度 ≥ 1200 epx 时为停靠的非模态面板，更窄时使用现有模态抽屉。

## 后果

- 界面规范 §2.1、§2.3、§2.5、§3.1、§3.2 与 KEY-07 按本决定同步更新。
- 设计值断言（颜色、尺寸、页面顺序）随新设计更新；审批、AI 控制、无障碍阈值相关断言只增不减。
