# 0036 工作台最终 IDE 布局

- 状态：已采纳
- 日期：2026-11-20
- 决策者：维护者
- 相关：在 [ADR 0035](0035-workbench-native-ide-dual-accent.md) 基础上细化布局与页面结构；保留 [ADR 0003](0003-workbench-approval-for-mcp-writes.md)、[ADR 0028](0028-workbench-visual-design-eplanmcp.md) 中的人工审批与危险确认流程，以及[工作台界面规范](../ui.md) §5 的审批与 AI 控制红线

## 背景

维护者提供了最终设计稿（`bin-build/design/workbench-final-design.html`，不随发布分发）：38 epx 标题栏居中 Ctrl+K 命令面板、60 epx 图标加短标签的活动栏、左侧工程树或上下文列表、26 epx 状态栏、会话弹出层，以及合并后的页面结构。设计稿中有几处与审批红线冲突，另有几处功能没有宿主数据支撑。

## 决定

1. 产品名为「自动化工程工作台」／Automation Engineering Workbench。38 epx 标题栏显示渐变图层标志、产品名、斜线与页名。项目面包屑读取当前工程文件名。居中搜索入口用 Ctrl+K 打开命令面板，窗口最大化按钮支持 Windows 贴靠布局。
2. 活动栏宽 60 epx，七个活动页按项目、协作、MCP、客户端、检查、审计、日志分组排列，设置固定在底部。快捷键为 Ctrl+1…7、Ctrl+,。协作图标显示待批数，调用计数在 AI 调用记录胶囊。项目、审批与设置左栏分别宽 262、260、228 epx，最小窗口下均为 214 epx。页面工具栏与筛选条为 44／38，表单控件 32，树行 28，表头 34，状态栏 26。字号使用 9 至 18 epx 的设计阶梯。
3. 普通写请求的拒绝键在左，用次级样式，批准键在右，用品牌实底，两键高 32 epx，无默认、取消或访问键。Enter 永不批准，Esc 不拒绝。破坏性请求以品牌实底拒绝键为默认，危险描边批准键打开确认面板。面板取消为默认与取消键，实红确认键保留 Alt 访问键，两键高 36 epx。确认键不响应 Enter。状态栏审批入口只导航至设置的 AI 分区。
4. 浅色、深色、钴蓝和青碧采纳最终设计的表面、图标、语法和差异颜色。五套调色板逐值采用最终设计，半透明表面保留 alpha。系统高对比设置选用设计稿的 Night Sky 黑底、白线、黄选中主题。测试固定每对颜色在实际表面上合成后的对比度。界面字体与等宽字体链见界面规范 §2.2。
5. 编译计数来自最近一次编译，审计头只在已验证且没有更新事件时显示勾号。会话显示未验证标记，可从状态栏打开；会话弹出层不提供原生交叉引用开关。待批计数留在协作图标，审批模式只在状态栏播报。用户组、端口占用、防火墙问题显示在标题栏下方。忙碌进度卡位于右下方，一般操作反馈在底部居中。调用详情在内容宽度 ≥ 1200 epx 时停靠，更窄时使用模态抽屉。页面只显示已有数据；没有块路径的审批不能关联到编辑器差异，宿主未提供的工程事实留空。

## 后果

- 界面规范 §2.1、§2.3、§2.5、§3.1、§3.2 与 KEY-07 按本决定同步更新。
- 颜色、尺寸、位置与反馈入口随设计逐项核对。审批、AI 控制、键盘和焦点行为继续按原门禁验证。
